# Security Policy

## Scope

This repository is three small gitconfig files and setup instructions. It contains no service and no library. In scope:

- A setting that weakens signing or credential handling without the reference saying so
- Setup instructions that would leave insecure file permissions behind
- A setup instruction that would leave insecure file permissions behind

## Out of scope

- A vulnerability in Git or in a credential helper itself, report that upstream

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
